I'll make a tutorial using C++. Note that I am using an outdated version of C++. It's C++98. However, this version is enough for you to learn Object-Oriented Programming

### Tips

How do I actually learned how to code? My method is simple, I separate it into two.

 - Memorize syntax
 - Code analysis

First, I memorize the syntax so I can code it on my own. Then I do code analysis by asking AI code snippets I don't understand.

## Basics

I want you to focus on these things:

* For Loops
* If-Else Statements
* While Loops

If you are proficient in these, you can understand most of it.

### For Loops

```cpp
for (initialization; condition; update)
{
    //Code to repeat
}
```

### If-Else Statements

```cpp
if (condition1)
{
    //Code to run if condition1 is true
}
else if (condition2)
{
    //Code to run if condition2 is true and condition1 is false
}
else
{
    //Code to run if all conditions are false
}
```
### While Loops

```cpp
while (condition)
{
    // Code to repeat while the condition is true
}
```
